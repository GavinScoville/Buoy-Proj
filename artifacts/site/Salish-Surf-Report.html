Ray Tracing

Across the Pacific

1,600 km off the coast, the Ocean Papa buoy collects wave data. Using this information, we can infer the trajectory of waves as they travel across the Pacific. This map uses spherical trigonometry to calculate the azimuth and great-circle path of each wave. It does not yet include the Coriolis effect — coming soon.

Strait of Juan de Fuca

At the entrance of the Salish Sea, the Neah Bay buoy provides us basic wave data. No other surf models currently incorporate how these waves refract across the Strait. This ray-tracing diagram illustrates how the coastline bends and redirects incoming wave energy. A simple algorithm currently predicts wave height by holding energy flux constant.

Islands Region

The rays linearly interpolate between the Port Angeles Buoy and the New Dungeness Buoy. Waves pass over many underwater features but only experience friction and thus refraction when the depth is less than half the wavelength.

Spectral Model (Parabolic Mild-Slope)

A directionally spread sea state from the Neah Bay buoy is marched shoreward across 10 m bathymetry, capturing refraction, shoaling, diffraction and depth-limited breaking.
